# Konumu olmayan serbest fonksiyon bildirimi

Compiler-valid makro, etkin `pay(wallet: &Wallet)` gövdesi üretirken HIR hem Function hem source veriyordu; fiziksel kaynak range'i bulunamıyordu. Eski if-let zinciri bildirimi düşürüp gerçek Wallet::debit metodu dışında 0 çağrı ve 0 issue ile yanlış temiz rapor üretiyordu.

Kaynak okuyucu gerçek `ModuleDef::Function` bildirimi için her durumda mevcut global `Unsupported` sözleşmesini korur. Fiziksel kaynak varsa eski yol/satır/mesaj değişmez. Source veya range yoksa Cargo modelinin kök kaynak yolunda, gerçek HIR fonksiyon adını içeren fallback issue üretir. Sahte Method, module-self veya TypeShape eklenmez; genel serbest fonksiyon analizi açılmaz.

Gerçek Cargo kontrolünden geçen makro ve normal karşılaştırmalar public `RustProject` → `CheckProject` üzerinden sınanır. Makro fallback'i, Wallet::debit seçilince de global kalır. Normal karşılık attribute başlangıcı olan lib.rs:19'u korur; cfg dışı fonksiyonlar HIR bildirimi olmadığı için issue üretmez. Ayrı learning test etkin pay için has_body=true, source=true ve location=Err("source range is unavailable") kanıtını taşır.

`target/rust-friends-journey/logs/free-function-behavior-red.log` gerçek boş-issue kırmızısını, `free-function-green.log` üç yeşil karşılaştırmayı kaydeder. İlk normal konum beklentisi 20'den attribute satırı 19'a düzeltildi; bu beklenti hatası davranış kırmızısı sayılmadı. Fiziksel konumu kaybeden üretim bozulması normal testi kırdı; kapalı fixture fonksiyonunu etkinleştiren input kontrolü cfg testini gerçek Unsupported raporunda kırdı. Her iki kaynak byte eş geri alındı; `free-function-faults.json` ve ilgili log'lar kanıttır.

Son hedefli doğrulama: aynı `target/rust-friends-journey`, dev/test debug 0, incremental 0, jobs 1, test threads 1. `cargo test --offline --locked -p law-of-demeter-rust-source`: 39 geçti, 0 hata/ignored (önceki 35 + 4 yeni). `cargo fmt --all --check` ve paket `cargo clippy --offline --locked -p law-of-demeter-rust-source --all-targets -- -D warnings`: exit 0. Exact komut/süre/çıkışlar `free-function-verification.json` içindedir.
